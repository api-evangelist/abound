# Abound

> Abound was a US tax-compliance API for platforms, marketplaces and fintechs serving the 1099
> economy: collect Form W-9 / W-8BEN / W-8BEN-E from payees, verify their TIN against IRS records
> in real time, then generate, file, correct, void and physically mail Form 1099-NEC, 1099-MISC,
> 1099-K and 1099-INT to federal and state tax authorities.

**Status: retired.** Abound was acquired (announced November 2024) and the service has been shut
down. The `withabound.com` DNS zone has no delegated nameservers, so the marketing site, docs,
status page and both API hosts return NXDOMAIN, and the `withabound` GitHub organization returns
404 (probed 2026-07-19). The only surviving first-party artifact is the official npm package,
which ships the complete API definition. Everything below is a historical record recovered from
that package — no endpoint listed here is callable.

## API

- [Abound API v4](https://www.npmjs.com/package/@withabound/node-sdk): 55 REST operations over
  Users, tax forms, TIN verifications, 1099 information returns, mailings, tax treaties,
  electronic delivery consents and drop-in-component access tokens.
- Production base URL: `https://production-api.withabound.com` (retired)
- Sandbox base URL: `https://sandbox-api.withabound.com` (retired, and the SDK default)
- Auth: HTTP bearer, where the token is `<appId>.<appSecret>`
- Versioning: URI path, `/v4`

## Specs

- [OpenAPI 3.1](openapi/abound-v4-openapi.yml): 55 operations, 39 paths, 149 schemas, 44 webhooks
- [AsyncAPI 3.0](asyncapi/abound-webhooks-asyncapi.yml): the 44 HMAC-signed webhook events
- [Overlay](overlays/abound-v4-overlay.yaml): API Evangelist annotations over the OpenAPI

## Conventions

- [API conventions](conventions/abound-conventions.yml): `Idempotency-Key` accepted on all 26 POST
  operations; page-number pagination via `page` capped at 100 records; `foreignId` as the
  customer-side correlation key; prefixed opaque ids (`documentId_`, `userId_`, `mailingId_`,
  `tinVerificationId_`, `tinFingerprint_`)
- [Authentication](authentication/abound-authentication.yml): single bearer credential, no OAuth,
  no scopes; webhooks verified with the `Abound-Signature` HMAC header
- [Error catalog](errors/abound-problem-types.yml): 400/401/404/409/500, status-code
  discriminated, custom JSON envelopes (not RFC 9457)
- [Data model](data-model/abound-data-model.yml): entity graph plus the 1099, TIN-verification and
  mailing state machines
